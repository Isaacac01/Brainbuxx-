# BrainBuxx BrainBuxx is a Flask-based virtual assistant inspired by modern AI chat experiences. It combines a premium ChatGPT-like frontend with a lightweight Rasa intent layer and a Gemini-powered reasoning engine, while keeping user conversations persistent in SQLite. ## Features - Flask + SQLAlchemy backend with user authentication - ChatGPT-inspired interface with responsive layout - Persistent conversations and message history - Searchable conversation list with rename and delete actions - Rasa-based intent classification with fallback behavior - Gemini API integration with graceful fallback responses - Opening screen animation and typing response effect - Secure password hashing and protected conversation access ## Tech stack - Backend: Flask, Flask-SQLAlchemy, Flask-Login - Frontend: HTML, CSS, vanilla JavaScript - AI: Rasa NLU + Gemini API - Storage: SQLite (ready for PostgreSQL migration) ## Run locally 1. Create a virtual environment: ```bash python -m venv .venv source .venv/bin/activate ``` 2. Install dependencies: ```bash pip install -r requirements.txt ``` 3. Create environment variables: ```bash cp .env.example .env ``` 4. Start the app: ```bash python app.py ``` 5. Open the app in a browser: ```text http://localhost:5000 ``` ## Security notes - Passwords are hashed with Werkzeug. - Sensitive API secrets remain in environment variables. - Conversation access is restricted to the authenticated user. ## Project structure - `app.py` – entry point - `config.py` – config values - `backend/` – auth, AI, chat logic, and database setup - `models/` – database models - `templates/` – HTML pages - `static/` – CSS, images, and JavaScript - `rasa/` – Rasa configuration and training data
